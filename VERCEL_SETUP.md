# Настройка деплоя на Vercel

Чтобы в браузере открывался **новый** интерфейс (лендинг NewDay + «Начать обучение», кабинет с вкладками Каталог / Марафон 7 дней), а не старый (Вход, Программы, Авторизация), нужно собирать именно папку **`frontend`** (новый React/Vite), а не `src/frontend` (старый SPA).

## Что сделать

1. Открой проект в Vercel → **Settings** → **General**.
2. В поле **Root Directory** должно быть ровно **`frontend`** (одно слово, без `src/` и без слэша в конце).
   - ✅ Правильно: `frontend`
   - ❌ Неправильно: `src/frontend`, `./frontend`, пусто (корень репо).
3. Нажми **Edit** → введи `frontend` → **Save**.
4. **Deployments** → у последнего деплоя **⋯** → **Redeploy** (или сделай новый коммит и дождись деплоя).
5. Открой **тот же** домен/URL, с которого заходила (preview или production). При необходимости обнови страницу с полным сбросом кэша (Ctrl+Shift+R / Cmd+Shift+R).

## Как проверить, что всё верно

- В логах сборки в Vercel должна быть команда **Vite** (например `vite build`), а не просто копирование HTML.
- После открытия сайта: первый экран — лендинг с кнопкой **«Начать обучение»** и блоками «Почему NewDay?»; по клику «Войти» / «Начать обучение» открывается кабинет с вкладками **Каталог**, **Мои курсы**, **Марафон 7 дней**, **Завершённые**. Если вместо этого видишь сверху вкладки «Вход», «Программы», «Мои курсы», «Марафон 7 дней», «Админ» и форму «Авторизация» — показывается старый фронт, значит Root Directory указан неверно (например `src/frontend` или пусто).
