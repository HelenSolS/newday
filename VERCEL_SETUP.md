# Деплой на Vercel

Фронтенд (React/Vite) теперь в **корне репо**: `package.json`, `src/`, `index.html`, сборка → `dist/`.

**Root Directory в Vercel оставь пустым** (или удали значение) — сборка идёт из корня. После пуша в `dev` Vercel сам подхватит Vite и соберёт проект.

После деплоя: лендинг с кнопкой «Начать обучение», кабинет с вкладками Каталог / Марафон 7 дней. Старый SPA перенесён в `_old_src/frontend/`, бэкенд — в `_old_src/backend/`.
